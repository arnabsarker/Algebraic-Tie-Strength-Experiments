# Algebraic Topological Centrality Measures

This repository provides Julia scripts for computing **Edge PageRank** and **Hodge Decomposition** centrality measures. These tools are used to characterize tie strength in higher-order social networks, as detailed in the following research:

> Sarker, A., Seby, J. B., Benson, A. R., & Jadbabaie, A. (2026). **Algebraic topological characterizations of tie strength in higher-order social networks.**
> 
> *A related preprint is available on [arXiv](https://arxiv.org/abs/2108.02091).*

---

The repository contains the following files:

| File / Directory | Description |
| :--- | :--- |
| `Data/` | Contains a sample dataset and `relabel_for_julia.jl` for node preprocessing. |
| `SeedDecomposition.jl` | Computes Hodge Decomposition centrality measures for a dataset. |
| `EdgePR.jl` | Computes Edge PageRank vectors and their Hodge Decomposition. |
| `SimplicialLaplacians.jl` | Helper functions for generating boundary operators. |

**Note:** The full datasets analyzed in the paper can be found in the [Algebraic-Tie-Strength-Data](https://github.com/arnabsarker/Algebraic-Tie-Strength-Data) repository.

---

### Prerequisites
These scripts are written in **Julia** and have been tested on version 1.6.1. Ensure you have the following packages installed:
* `LinearAlgebra`
* `SparseArrays`

### Sample Usage

#### 1. Hodge Decomposition
To compute Hodge Decomposition centrality measures for a simplicial complex:
```bash
julia SeedDecomposition.jl <input_directory> <output_directory>

```

#### 2. Edge PageRank

To compute Edge PageRank centrality measures:

```bash
julia EdgePR.jl <input_directory> <output_directory>

```

### Optional Flags

* **`-c`**: This flag can be used to compute measures for the clique complex of the underlying graph, rather than the simplicial 2-complex generated by higher-order social interactions.
